# QR-Scanner-Pro
This is a JavaFX-based desktop application designed for PCs to scan QR codes quickly and offline. It uses the ZXing library for fast decoding, offers a clean and modern interface, and ensures privacy by working without internet. Ideal for users needing reliable, real-time QR scanning on desktop.
First run mvn clean install.
Navigate to C:\Users\aliak\IntellijIdeaProjects\QR-Scanner\src\main\java\block\qrscanner and run QRScannerApplication.java
